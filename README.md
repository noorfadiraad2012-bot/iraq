# Discord Video Player (Selfbot)

بث فيديو/صوت إلى روم صوتي في ديسكورد عبر WebRTC + FFmpeg.

> **تحذير مهم:** استخدام Selfbot (تشغيل بوت بحساب مستخدم عادي) **يخالف شروط خدمة ديسكورد** وقد يؤدي إلى **حظر الحساب نهائياً**. استخدمه على مسؤوليتك فقط.

---

## المتطلبات

- Node.js 18 أو أحدث
- FFmpeg (أو سيتم استخدام `ffmpeg-static` تلقائياً)
- على Linux: يُفضّل وجود `python3` لـ yt-dlp، أو سيتم تنزيل binary مستقل

## الإعداد

1. عدّل ملف `.env`:

```env
DISCORD_TOKEN=توكن_حسابك
PREFIX=!
ALLOWED_IDS=ايدي_حسابك
STREAM_TYPE=go-live
VIDEO_WIDTH=1280
VIDEO_HEIGHT=720
FRAME_RATE=30
VIDEO_BITRATE=5000
```

- `ALLOWED_IDS`: ضع آيدي حسابك فقط (يمكنك فصل أكثر من آيدي بفاصلة). بدونها لن يعمل أي أمر.
- لا تشارك التوكن مع أحد — أي شخص يملكه يتحكم بحسابك.

2. التثبيت والتشغيل:

```bash
npm install
npm start
```

3. (اختياري) ملفات محلية: ضع الفيديوهات داخل مجلد `media/` فقط، ثم شغّل باسم الملف:

```text
!play video.mp4
```

4. (اختياري) لتجاوز قيود يوتيوب أحياناً: ضع ملف `cookies.txt` في جذر المشروع.

---

## الأوامر

| الأمر | عربي | الوظيفة |
|-------|------|---------|
| `!cam <رابط>` | `!كام` | بث كاميرا (صوت مباشر في الروم) |
| `!play <رابط>` | `!شغل` | بث شاشة (Go-Live) |
| `!stop` | `!وقف` | إيقاف البث |
| `!leave` | `!اخرج` | مغادرة الروم الصوتي |
| `!help` | `!مساعدة` | عرض الأوامر |

---

## المصادر المدعومة

- روابط YouTube
- روابط مباشرة: `mp4`, `mkv`, `webm`, `mov`, `m4v`, `m3u8`
- ملفات محلية داخل مجلد `media/` فقط (حماية من path traversal)

---

## تحسينات الأمان في هذا الإصدار

- التحقق من أن التوكن ليس placeholder
- الأوامر تعمل فقط لـ `ALLOWED_IDS`
- cooldown بسيط بين الأوامر
- الملفات المحلية مقيدة داخل `media/`
- قبول روابط `http`/`https` فقط
- حدود معقولة للدقة والـ bitrate والـ fps
- معالجة أفضل للأخطاء وإيقاف نظيف للعمليات
